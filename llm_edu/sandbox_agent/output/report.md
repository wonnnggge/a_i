# CVE 영향도 점검 보고서

## 확인 대상
- Apache Log4j 2.14.1
- Cisco AnyConnect 4.9.0

## 확인 방법
1. 자산 목록은 `input/assets.md`에서 확인했다.
2. CVE는 `cve-lookup` 도구로 조회했다.
3. 벤더 공지는 Cisco 사이트에서 확인을 시도했으나, 조회한 URL은 404로 응답했다.

## 결과

### Apache Log4j 2.14.1
- 조회 CVE: CVE-2021-44228
- 판정: **영향 받음**
- 근거: `cve-lookup` 결과에서 영향 버전이 `2.0-beta9 ~ 2.14.1`, 수정 버전이 `2.17.1`로 확인됨.

### Cisco AnyConnect 4.9.0
- 조회 CVE: 관련 CVE를 `cve-lookup`으로 조회했으나 등록된 항목을 확인하지 못함.
- 판정: **판정 불가**
- 근거: 사내 도구 기준으로 매칭되는 CVE 정보가 없었고, 벤더 공지 확인도 404로 실패함.

## 요약
- 영향 받음: 1건
- 판정 불가: 1건
